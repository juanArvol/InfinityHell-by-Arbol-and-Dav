ARCHIVOS CREADOS:
─────────────────
1. Game/Engine/Profiling/FrameProfile.java
   - Estructura de datos para capturar tiempos de subsistemas por frame
   - Campos: activeProjectiles, fps, simulation, physics, collision, rendering

2. Game/Engine/Profiling/SubsystemTimer.java
   - Timer de alta resolución con System.nanoTime()
   - API: start(), stop(), getElapsedMs(), getElapsedNanos()

3. Game/Engine/Profiling/ProfileCollector.java
   - Acumula FrameProfiles de múltiples frames
   - Ring buffer configurable (evita memory leak)
   - Genera estadísticas: promedio, min, max
   - Export a CSV para análisis externo
   - Detección automática de cuellos de botella

4. Game/Engine/Profiling/ProfilingConfig.java
   - Singleton de configuración global
   - Modos de aislamiento (rendering, simulation, collision)
   - Auto-export al shutdown

5. Main/Debug/ProfilingCommand.java
   - Comandos de usuario: startStressTest(), stopProfiling(), etc.
   - Configuraciones rápidas para pruebas de diagnóstico

ARCHIVOS MODIFICADOS:
─────────────────────
1. Game/Engine/Systems/CollisionsSystem.java
   - Agregados: collisionTimer, broadPhaseTimer, narrowPhaseTimer, dispatchTimer
   - Métodos públicos para acceder a tiempos medidos
   - Timer.start() al inicio de update()
   - Timer.stop() al final de update()

2. Game/World/Core/WorldManager.java
   - Agregados: updateTimer, simulationTimer, renderTimer, frameCounter
   - Método getActiveProjectileCount() para contar bullets
   - Genera FrameProfile y lo registra en ProfilingConfig
   - Mide simulation en update() y rendering en draw()

3. Game/Engine/Profiling/ProfileCollector.java
   - Agregado: updateLastFrameRenderTime() para actualizar rendering time

4. Main/Bootstrap/GameWorldBootstrap.java
   - Línea comentada para activar profiling: ProfilingCommand.startStressTest()

CÓMO USAR:
──────────
OPCIÓN 1 — Descomentar en GameWorldBootstrap:
   // Main.Debug.ProfilingCommand.startStressTest();

OPCIÓN 2 — Desde código:
   Main.Debug.ProfilingCommand.startStressTest();
   // ... jugar disparando con WeaponPistola (360 bullets/shot) ...
   Main.Debug.ProfilingCommand.stopProfiling();
   // Resultado: profiling_results.csv

OPCIÓN 3 — ProfilingConfig directo:
   ProfilingConfig config = ProfilingConfig.getInstance();
   config.setEnabled(true);
   config.setMaxFrames(5000);
   // ... jugar ...
   config.printSummary();
   config.exportCSV("profiling_results.csv");
